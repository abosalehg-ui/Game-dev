## 📖 عن اللعبة

**من الغرفة للقمة** لعبة محاكاة تطوير ألعاب مستوحاة من Game Dev Tycoon، مصممة للجوال أولاً وباللغة العربية. النسخة الثانية أعيدت كتابتها من الصفر بأدوات حديثة بدل ملف HTML واحد بستة آلاف سطر.

| النظام | الوصف |
|---|---|
| 🏷️ **الاسم يحدد الموضوع** | اكتب «ملحمة الصحراء» فتكون لعبتك 🐪 صحراء — قاموس 333 كلمة عربية مع فهم للبادئات والإضافة |
| 🏗️ **6 مراحل** | من غرفة النوم إلى ناطحة السحاب، لكل مرحلة مشهد إيزومتري خاص |
| 🎯 **11 نوعاً × 15 موضوعاً** | مصفوفة توافق مخفية + أذواق سوق تتغير كل سنة |
| 👥 **فريق حقيقي** | 5 أدوار × 4 مستويات، معنويات وترقيات واستقالات |
| 📊 **سوق تنافسي** | 4 استوديوهات AI تنافسك على الحصة وجائزة لعبة العام |
| 📦 **سلاسل وعقود** | IPs وأجزاء تالية وDLC وعقود ناشرين وقروض بنكية |
| ⭐ **Prestige** | الإفلاس بداية جديدة أقوى |

## 🏗️ البنية التقنية (v2)

```
src/
├── lib/
│   ├── data/        بيانات اللعبة الثابتة (أنواع، مواضيع، قاموس، مراحل...)
│   ├── core/        منطق نقي قابل للاختبار
│   │   ├── sim.ts        معادلات التقييم والمبيعات والسوق
│   │   ├── topic.ts      اشتقاق الموضوع من الاسم العربي
│   │   ├── balance.ts    كل أرقام الموازنة في مكان واحد
│   │   ├── save.ts       حفظ/تصدير مع تعقيم كامل للمدخلات
│   │   ├── model.ts      أنواع الحالة
│   │   ├── state.svelte.ts   الحالة التفاعلية ($state)
│   │   └── game.svelte.ts    طبقة أفعال اللعبة
│   ├── scene/       المشهد الإيزومتري (Canvas 2D، معزول عن المنطق)
│   └── ui/          مكونات Svelte (تبويبات، نوافذ، HUD)
```

| التقنية | لماذا |
|---|---|
| **Svelte 5 + TypeScript** | واجهة تفاعلية بلا أخطاء أنواع، وحجم نهائي ~53KB مضغوطة |
| **Vite** | تطوير فوري وبناء محسّن |
| **Canvas 2D إيزومتري** | مشهد حي خفيف يعمل على أضعف الجوالات (بدل Three.js) |
| **Vitest** | 45 اختبار وحدة للمنطق النقي |
| **PWA** | يعمل دون اتصال ويثبّت كتطبيق |

## 🧑‍💻 التطوير محلياً

```bash
npm install
npm run dev            # خادم تطوير
npm test               # اختبارات الوحدة (اشتقاق الموضوع، المحاكاة، الحفظ)
npm run check          # فحص أنواع TS + Svelte
npm run build          # بناء الإنتاج → dist/
npm run build:single   # ملف HTML واحد مكتفٍ بذاته → dist-single/
```

**ملاحظات صيانة:**

- **كل أرقام الموازنة** في `src/lib/core/balance.ts` — لا أرقام سحرية داخل الدوال.
- **قاموس المواضيع** في `src/lib/data/topics.ts`. لا كلمة تحت موضوعين — اختبار يمنع ذلك.
- **أي تغيير في مخطط الحفظ** يمر عبر `sanitizeSave` في `save.ts` — الجهة الوحيدة المسؤولة عن التحقق.
- **المشهد** يقرأ `SceneProps` فقط ولا يعرف شيئاً عن الحالة — أي تطوير بصري لا يمس المنطق.
